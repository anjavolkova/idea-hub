Save to your website

Connect once on this laptop. After that, the Save to website button puts this board on your website, where visitors see it first and can start their own. Their changes never touch yours.

  1. Open GitHub's new key page.
  2. Under Repository access, pick Only select repositories, then idea-hub.
  3. Check that Permissions shows Contents: Read and write, then click Generate token.
  4. Copy the key and paste it above.

The key stays in this browser. It can only change files in idea-hub.
